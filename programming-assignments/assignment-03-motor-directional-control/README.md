**H-Bridge DC Motor Direction Control (Basic Schematic)**
This repository holds a basic Proteus simulation of an H-bridge circuit used to control the direction of a DC motor.   
**Components**
- DC Motor: The load placed in the center of the bridge.   
- NPN Transistors (Q1, Q2, Q3, Q4): Four identical 2N2222 transistors acting as switches.   
- DC Power Source (BAT1): Powers the motor and circuit.   
- Switch (SW1): Controls the state of the circuit.   
**How It Works**
The transistors are arranged in an "H" shape around the motor. By switching on different diagonal pairs, you change the path of the current flowing through the motor. Reversing this current flow reverses the motor's direction of rotation.
